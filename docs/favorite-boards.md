# Private creative boards

Favorites preserve the existing `ultraclipart-favorites` ID list. Versioned board metadata uses a separate local key; every writer rereads it before an update. Original favorites are retained without inventing historical dates. A new save records its actual ISO instant and displays the browser's local date/time. Multi-board membership, notes, names, descriptions and five board colors are stored on the device. There is no account or automatic cross-device synchronization.

The page supports named boards, editing, per-design organization and notes, multiple boards, title/note search, saved-date filters, ordering, bounded eight-card metadata pages, bulk assignment/removal, undo for removed favorites and deleted boards, and versioned JSON backup export/import. Deleting a board leaves favorites intact. Import merges instead of replacing. Inputs and backups are bounded; unknown fields, unsafe image URLs, invalid dates and dangling board memberships are discarded. Display uses text nodes for user-provided content. No board names or notes are sent to a server. Backup export is an intentional private local file download, separate from catalog file-information pages.

Publication/license eligibility remains controlled by the catalog. Unavailable saved IDs show a notice while available items keep working. Quota failures leave prior favorites intact and report the failure; they never falsely report a successful save. Same-tab dialogs use native modal focus and Escape handling. Other-tab storage changes refresh the current view, and cancelled old metadata requests cannot overwrite a newer board/filter result.
