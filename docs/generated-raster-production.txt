It uses the same move/scale/rotate/crop/opacity image layer contract as the supplied collections, with separate added text and shapes.

Create a reviewed, at-most-50-item data/waves/WAVE-plan.json with unique IDs from the topic's fifty-composition brief. The native source is retained. The export command is:
  PDFTOPPM_BIN=/path/to/pdftoppm python scripts/produce-raster-wave.py --wave WAVE

The exporter locks its wave and binds each item’s resume evidence to its source, metadata, quality policy, exporter, helper, profile and research bytes. It verifies all export and proof bytes before reuse and regenerates damaged or changed outputs. Deferring an unrelated item does not invalidate already verified neighboring exports. It never uploads or edits the live catalog. Original WebP must decode to exactly the source RGBA pixels. Only thumbnails are resized. CMYK conversion uses the checked-in licensed GRACoL2006 profile, relative colorimetric intent and black-point compensation. Color is zeroed only where alpha is exactly zero, which cannot change any visible composite. The complete 8-bit alpha mask remains lossless.

Try native-resolution lossless JPEG2000 CMYK first, followed by high-fidelity candidates of at least 48 dB encoder target and at most 1.8 alpha-weighted CMYK channel RMSE. These lossy candidates are explicitly recorded as lossy; do not claim byte-exact or lossless CMYK. Independently decode actual four-channel data, verify dimensions and alpha, render with Poppler and the GRACoL profile, cross-match every PDF against all wave WebPs, and inspect actual rendered pages. Metrics are gates, not a substitute for visual review or a guarantee of physical print quality. No PDF/X certification is claimed. The full 2.75 MB ICC cannot fit the standard limit, so the PDF references the registered CGATS TR 006 output condition without embedding it.

The standard publication budget is 980,000 bytes, reserving room below the user's 1,000,000-byte hard cap for editor additions. If no native-resolution candidate meets both quality and size gates, hold that illustration; do not lower the quality floor, resize its original, replace it with a low-detail stand-in, or count it as a published design. Keep the full source for further work.
